# New Memory Patient

Use this checklist for a patient being evaluated in the Memory Disorders Clinic for the first time.

<div class="guide-meta">
  <span class="guide-tag">Initial visit</span>
  <span class="guide-tag">Memory clinic</span>
  <span class="guide-tag">Checklist</span>
</div>

</div>

<div class="guide-section">

## Before Dr. Morgan Enters

- [ ] Complete the MoCA [purple folder, instructions on how to perform in folder which you can take into the room with you].
- [ ] Complete the FAQ [purple folder].
- [ ] Complete the PHQ-9 [purple folder].
- [ ] Complete the GAD-7 [purple folder].
- [ ] You'll need a pen and clipboard for this.
- [ ] Obtain the GMN consent form by asking Caty or the social worker if patient is a memory patient located in Georgia.

</div>

<div class="guide-section">

## Before Entering the Room

- [ ] Review the referral reason.
- [ ] Review previous neurology or memory clinic notes.
- [ ] Find the most recent brain MRI or CT.
- [ ] Review available laboratory results.
- [ ] Review the medication list, smart phrase [.medscurrent].
- [ ] Identify who is providing collateral history.

</div>

<div class="guide-section">

## During the History

- [ ] Review the medication list with patient, relevant to memory, movement, and mood. Disregard all other medications.
- [ ] Write with a header and bullet list below. One header should be: Current Medications, Trialed Medications. Please the medications where needed, and include dosages, time taken, or reason for stopping medication.
- [ ] Determine when the cognitive symptoms began.
- [ ] Ask how the symptoms have progressed.
- [ ] Ask for examples of short-term memory difficulty.
- [ ] Ask about repetition, appointments, conversations, and misplaced items.
- [ ] Ask about language, navigation, judgment, and problem-solving.
- [ ] Review basic activities of daily living.
- [ ] Review instrumental activities of daily living.
- [ ] Confirm who manages medications and finances.
- [ ] Confirm whether the patient is driving.
- [ ] Ask about mood, sleep, hallucinations, and behavioral changes.
- [ ] Ask about falls, gait changes, tremor, or abnormal movements.
- [ ] Obtain collateral history from a family member or caregiver when available.

</div>

<div class="guide-section">

## Presenting the Patient

- [ ] Complete the appropriate neurologic examination.
- [ ] Review the cognitive testing results if they exist.
- [ ] Prepare a presentation for Dr. Morgan, including medication.
- [ ] Identify the primary cognitive concern and functional changes.

</div>

<div class="guide-section">

## After the Visit

- [ ] Confirm ordered laboratory testing.
- [ ] Confirm ordered imaging or neuropsychological testing.
- [ ] Confirm referrals.
- [ ] Confirm when the patient should return.
- [ ] Complete and given patient the first-patient visit sheet. Fill out when pt should return (ex: 4 months) and cross out/write down what needs to be completed before next appointment.
- [ ] Record where the patient should return if the follow-up is not with Dr. Morgan.
- [ ] Give the patient the clinic information sheet and any referrals needed with Dr. Morgans signature. If they are virtual, they will receive a call to schedule.

Ask and follow Dr. Morgan's instructions when he provides a different return timeframe.

</div>

<div class="guide-callout">

<strong>Important</strong>

Complete all required questionnaires before Dr. Morgan enters the room. Documents to scan should have a patient sticker placed on them (the front). Please place them in the pink folder.

</div>
